Unity DOTS Physics Tower Defense

Info

  • Engine: Unity
  • Languages: C#
  • Platform: PC
  • Time frame: 1 Month (40 Hours/Week)
  • Team Size: 2

Overview

The project was part of my onboarding process as an intern at Head First Studios. The goal of the project was to get to know the Unity DOTS framework and the Job System. I collaborated closely on all functionality with my fellow programming intern, William Melander.

Contributions using Job System

  • ● Physics-based Enemy Movement System.
  • ● Damage Application System.
  • ● Enemy / Projectile Culling System.
  • ● Tower Attack System (Ranged and AOE Towers).
  • ● Projectile Management System (Direct damage transfer and explosive damage).
  • ● Enemy Spawning System.
  • ● Damage Flash System.

Other Contributions

  • ● Freefly Camera using Input System Package.
  • ● HUD UI using UI Toolkit.
  • ● C# Event and Unity Event Bus.
  • ● Earning and spending of currency.
  • ● Screen to World Tower Placement.
  • ● Custom Inspector Windows for Tower and Projectile Authoring Scripts.
  • ● Object Pool for World Space Currency Reward UI.
